# Pitch film templates

Use only the template sections needed for the current request.
These are small records inside the existing content packet, not new runtime state.
Keep product truth in its existing sources and asset lineage in the existing manifest.

## Shared brief

```text
Brief ID / revision / direction decision:
Format: sales pitch | product demo | short ad | brand story
Destination / aspect ratio / target duration / viewing conditions:
Audience / current problem / current alternative:
On-screen protagonist / their immediate goal / obstacle:
Single-minded proposition:
Think / feel / do after viewing:
Customer language / source / permission (or explicitly hypothetical wording):
Reason to believe / visible mechanism:
Main objection / truthful answer / limits:
Claim ID | exact permitted claim | source path + revision | status + limitation
CTA / destination truth:
Existing assets / source revisions / rights / missing evidence:
Accepted concept / script / transcript revisions, if any:
Selected production operation / existing tool binding / authority / constraints:
Requested stages / reused artifacts / skipped stages and reasons:
Open decisions / blocked action / return condition:
```

## Format choices

These durations are planning ranges. The brief owns the actual target and the read-through tests it.
Each form still uses six to eight causal beats; combine actions rather than cram eight scenes into a short slot.

| Format | Starter prompt | Suggested allocation | Evidence and stopping condition |
| --- | --- | --- | --- |
| Sales pitch | “Write for [decision audience], through [protagonist], to earn [next conversation]. Answer [main objection] with [supported proof].” | 45–90 seconds: problem, stakes, mechanism, proof, objection, invitation | Source business and product claims. Stop unsupported comparisons or promises before pitching them. |
| Product demo | “Show [one actual task], including [starting state], [real action], [observed result], and [next step].” | 30–60 seconds: goal, obstacle, input, action, result, limit, CTA | Actual capture proves behavior. A mock or simulated flow needs a visible label and cannot pass as live proof. |
| Short ad | “Make [one tension] recognizable, show [one mechanism], earn [one CTA] within [slot].” | 15–30 seconds: hook, cause, action, supported change, reason, CTA | Keep reading and disclosure time. An attention prediction is not a measured hook result. |
| Brand story | “Let [protagonist] pursue [goal] through [tension], making [brand value] visible through a concrete action.” | 30–60 seconds: situation, desire, friction, choice, consequence, invitation | Use permitted story and brand sources. Never imply a fictional scene is a real customer endorsement. |

A supplied shorter or longer duration overrides these ranges. Reassess story density and evidence needs.
For creator UGC, load the existing [script-bank judge method](../growth/ugc-creator-engine.md#format-discovery-loop).
Do not turn a single scoped film request into a creator program or script-volume campaign.
When UGC generation applies, preserve its script ID, judge verdict and actual human believability requirements.

## Exact transcript

This record owns literal wording. The A/V script and editor use its IDs.

```text
Transcript ID / revision / linked brief revision / approval:
ID | channel (UI/chat/overlay/caption/VO/dialogue) | speaker | exact text | order | source or copy-deck key
T01 | chat | ... | ... | 1 | ...
T02 | VO | ... | ... | 1 | ...
Caption mapping: [caption ID] reproduces [spoken ID], or adds [sourced information].
Absent channels: ... = none.
Changes since accepted revision / impacted beat IDs / recheck needed:
```

Chat punctuation, message order and speaker are literal. Do not substitute voiceover for exact chat text.
If the packet includes verbatim quoted customer material, preserve its permission and source restrictions.

## Script and review prompts

Use the [A/V columns](pitch-film-studio.md#causal-script) and add a six-to-eight-row beat sheet first.

- Writer: “Use brief [revision] and concept [ID]. Connect each beat through cause and consequence. Reference exact transcript IDs.”
- Director/editor: “Audit existing assets first. Turn script [revision] into capture, layer, sound and edit instructions using existing asset IDs.”
- Reviewer: “Inspect exact revision [ID] against claim sources. Find story, truth, timing and comprehension risks in that order.”

Record planned time slots separately from actual read-through results.
For an existing edit, report corrections and pickups; do not regenerate accepted footage without a demonstrated need.
