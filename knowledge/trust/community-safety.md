# Community And User Safety

## Applicability

Use this guide when users can create, share, discover, or message content.

## Required controls

Define content rules, moderation, reporting, blocking, escalation, age controls, and a support contact. Set a response target and an owner. Test abuse reporting, user blocking, appeal, and account recovery. Record the evidence and the unresolved risks.

Apple Guideline 1.2 now names nonconsensual intimate imagery, including AI-generated imagery, as content these apps must prevent and remove. Developers who fail to add safeguards, or who fail to fix violations after notice, can violate the Developer Code of Conduct. Apply this to user-generated content and to AI image tools before the next submission.

## Output

Write the controls and proof in `trust/COMMUNITY_SAFETY.md`.
