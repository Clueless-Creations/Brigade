# Review code quality

Read the applicable repository `AGENTS.md` and [code quality review procedure](../../../docs/guides/code-quality-review.md).
Use the requested base, head, and focused or deep scope. Follow that procedure once.
If this agent implemented the change, assign the review to an independent agent or report that independence is missing.
Return evidence and findings in the current task. This command performs a read-only review and grants no additional authority.
